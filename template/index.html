Help center

Quick answers for capturing, managing, and exporting your records.

Frequently asked questions

How do I create a record?

From the dashboard, upload a file, paste a screenshot, use the webcam, or type/speak a note. Choose an optional name and press Extract & Save.

Where can I see all my records?

Open Records from the top navigation. Use the search field and record-type filter to narrow the library.

Can I correct extracted information?

Yes. Open any record, update its fields, and choose Save Edits. The structured TXT file is updated as well.

Which export formats are available?

Each record can be downloaded as TXT, PDF, or CSV. Original uploaded images can also be downloaded from the record page.

Why did AI extraction use sample data?

If no Gemini API key is configured, SBS uses a safe offline demonstration fallback so the workflow remains available.

How do I add an audio record?

Choose an audio file or use the live voice control, enter a title if needed, set the category beside the live note field, and select Save audio record. Audio files are limited to five minutes.

What happens when I delete a record?

The record is moved to the recycle bin instead of being removed immediately. Open the Recycle bin from the Records page to restore it or permanently delete it. Records are automatically removed after ten days.

Can I export more than one record?

Yes. Select records in the Records page, then choose Excel or CSV export. Excel includes formatted headers, borders, filters, and print-friendly layout.

Need more help?

For project support, contact the SBS team and include the record number and a short description of the issue.

Quick troubleshooting

  • Refresh with Ctrl + F5 if the interface looks outdated.
  • Allow microphone or camera permissions when using live capture.
  • Use a supported image or audio format and keep audio under five minutes.
  • Check the Records page after saving to search, edit, export, or move an item to the recycle bin.

Need technical support?

When reporting an issue, include the page name, record number if available, browser, and the action that failed.
